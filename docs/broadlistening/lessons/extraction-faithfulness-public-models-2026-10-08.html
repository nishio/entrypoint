Opinion Extraction Faithfulness: Retesting with Public Models and Prompt Improvement

Translated from the Japanese original: wiki/analyses/extraction-faithfulness-public-models-2026-10-08.md (commit 3459fc6). Machine-translated by Gemini and not yet reviewed by NISHIO Hirokazu.

Summary: In the opinion extraction stage of Kouchou-AI (広聴AI), the meaning of the original text can be rewritten even if the processing completes successfully. We compared 31B, 27B, and 2B public models on the same footing using a Japanese challenge set and public data. The reversal of sarcasm polarity occurs even in 27B and 31B, and possibilities and suggestions are strengthened to "should" due to the influence of the input/output examples in the default prompt. With an extraction prompt that adds rules and a single line "confirm the true intention first", rewrites in the unused test set are reduced to 0 cases for 31B and 2 cases for 27B, but the output leans towards being a direct copy of the original text. Small models fail to perform extraction without JSON grammar constraints.

Summary of an experiment (41 iterations) run in an unattended long session from 2026-10-07 to 08. The numbers are copied from the runs in the experiment repo. The runs and challenge sets are in a private experiment repo, and only the summaries and judgments are placed here.

A record of pursuing the Open Questions from local-llm-extraction-faithfulness-2026-10-05 using a challenge set synthesized with public data. The existing observation (when extracting Japanese opinions from short sentences in other languages using a small local model, the reversal of the subject occurs even if the processing finishes) was a visual inspection of 6 posts, so we made it into a form that can be counted by type.

Scaffolding

  • Kouchou-AI is fixed to main as of 2026-10-06 (commit a12d68e2). For extraction, the path of provider="local" was directly copied: system = default EXTRACTION_PROMPT, user = 1 comment, temperature 0, response_format = JSON schema of ExtractionResponse (strict), and the response is read with the same rules as parse_extraction_response.
  • Models (all public weights): gemma-4-31B-it, Qwen3.8-27B (NVFP4), Qwen3.5-2B (Q4_K_M, CPU delivery via llama.cpp). 31B / 27B are delivered via OpenAI-compatible APIs.
  • Data:
    • Public data: sample_comments.csv (400 Japanese items), example-polis.csv (342 English items)
    • Challenge set: Synthesized 20 items x 10 types of short Japanese sentences prone to rewriting (hearsay and the poster's stance, kinship terms, emotions, short commands, repetitions, interrogative sentences, sarcasm, greetings/cheering, possibilities and suggestions, conditional sentences). It does not include real people or organizations. Divided into a set for creating prompts (dev 100) and for testing (test 100), and test was not run while creating the prompts.
  • Scoring: "Words to keep" and "Words that must not appear" were attached to each item, counted mechanically, and both failures and passes were visually inspected. Comparing only by the number of mechanical passes changes the ranking (narrow anchors fail models with many paraphrases, and anchors containing surface words of the original text pass models that have reversed).

Findings

1. Rewriting occurs in Japanese as well. Types are separated by lineage rather than model size

With the default prompt, the following rewrites occurred in both 27B and 31B (all visually confirmed):

TypeOriginal → Extraction
Reversal of sarcasm polarity"A meeting to hold a meeting, it is truly meaningful." → "Meetings to hold meetings are meaningful" (both models 3/3)
Making possibilities/suggestions obligatory"Personally, I think it would be nice if the library's opening hours were a little longer." → "...should be longer" (both models)
Turning emotions into evaluative words"I'm really grateful that the library is now open until night." → "...is beneficial"
Strengthening certainty"I have never heard of such a story." → "The story that... is not a fact"
Omission of short commands"Don't come out." "Shut up." → Empty (Qwen3.8-27B only)
Neutralization of questions"Do you think childcare workers can live on this salary?" → "Seeking opinions on..."

The exact form of "making what someone else doubts into the poster's assertion" (the type from the original observation) was not seen in 27B and 31B. With English input, a type appeared where the antecedent of a conditional sentence turned into the poster's assertion, splitting into 2 items ("Should Phonons be part of future AI, this should be widely known" → "Phonons should be incorporated into future AI" + 1 item).

2. Some of the strengthening to "should" is taught by the input/output examples in the default prompt

The default input/output example 2 rephrases the input "need to do" to "should do" in the output. Just by returning these 2 lines to "need to do" exactly as in the input (without changing a single other character), the "would be nice → should" disappeared in both models, and the cases of adding "should", etc. despite the absence of words of obligation in the original text, decreased from 8→6 in 31B and 10→6 in 27B (out of 100 items).

3. Rules and a single line "confirm the true intention first" stop many types

After fixing the input/output examples, we added rules for subject, modality (do not strengthen weakness), conditions, emotions, sarcasm as true intention, questions as doubts, short commands as opinions, and empty for greetings without content (we removed "polarity", "do not add", and "prioritize preservation" which had no effect after taking off the rules one by one), added 1 pair of input/output examples for sarcasm, and added "even sentences that only introduce other people's troubles or facts should be left as opinions" to the subject rules. Finally, adding a single line "Before writing an opinion, determine whether the original text is sarcasm or rhetorical, and write it after confirming the true intention" greatly fixed the sarcasm of reading dissatisfaction from quantity and time.

Comparison using the test set (120 items, scoring criteria fixed before looking at the output) which was not used to create the prompt:

Looking only at the effect of the single line "confirm the true intention first", the cases where the polarity could be preserved in 20 sarcastic items without words of dissatisfaction were 15→18 for 31B and 8→18 for 27B.

Side effects and limitations:

  • Direct copies of the original text increase (82→202 out of 400 items for 27B on public data). Rewriting does not occur, but the "~to omoimasu" (I think...) at the end of the sentence also remains. The total number of opinions is almost the same as the default, so it doesn't get leaner in terms of numbers.
  • Comments stating only facts can sometimes be made empty (2 to 4 cases out of 400 public data items).
  • Some sarcasm requiring common sense remains ("It takes half a year for the benefits to arrive, the fun will last a long time" → "The fun will last a long time", 27B). Modifying the details of the rules can sometimes bring back sarcasm that was previously fixed.

4. Among extraction rewrites, polarity is what affects downstream

When extraction results flow to embedding → clustering → labels (an approximation substituted by k-means without UMAP), the reversal of sarcasm goes into the cluster of gratitude and convenience improvement, and voices of dissatisfaction are counted on the side of agreement. The "should-ification" or "is not a fact-ification" does not move from the cluster of the same topic, and the impact appears in the strength of the main text quoted in the report. Note that the reorganization of clusters when changing the prompt is the same magnitude as the reorganization from just changing the initial value of k-means, so differences in extraction cannot be measured by comparing whole clusters.

5. Small models require JSON grammar constraints

When Qwen3.5-2B is run in a delivery that ignores response_format, 62 out of 90 items in short sentences, greetings, and interrogative sentences do not become JSON (they start writing explanations), which would stop the process at the extraction stage in Kouchou-AI. Delivering with the JSON schema (grammar constraint) of llama.cpp makes the failures 0/400. Instead, in the default prompt, for 7-9% of short commands and greetings, it returns the sentences from the input/output examples verbatim ("Go home." → "AI can optimize the energy grid, reducing waste and carbon emissions."). Since the format is correct, it passes the parsing and is counted as an opinion. With the prompt with rules, this became 0.

The prompt with rules (with the 1 line to confirm the true intention first) also works for 2B. In the unused test of 117 items, the passes increased from the default 82 → 98, and sarcasm with clues increased from 1 → 7 out of 10 items. However, the results for 2B fluctuate greatly: when the same prompt is sampled and run 5 times, the passes move by 18 items between 85 and 103, and differences from fine adjustments to the prompt (reducing rules, adding input/output examples, wrapping the comment in directives) fell within this fluctuation. Sarcasm requiring common sense ("It takes half a year for the benefits to arrive, the fun will last a long time") can only be read in 3 out of 10 cases (2 to 7 cases in 5 samplings, average 4.2 cases), and it remains 3 cases even with a majority vote of 5 times. 2B also sometimes copies only the first half of the original text and stops ("What a splendid plan, although none of the residents knew about it." → "What a splendid plan"). This occurs with the same sentence even when the grammar constraint is removed, so it is the model's reading, and it decreases to 0-2 cases with the prompt with rules.

6. Automated faithfulness checking (LLM judge) can also pick up sarcasm if it first makes the model write the true intention of the original text

When having an LLM judge "whether the extracted opinion has the same subject and polarity as the original text", against 209 visually inspected correct pairs, the 31B judge detected 20 out of 30 rewriting cases and falsely detected 16 out of 179 faithful cases. At this time, the judge also read sarcasm literally just like the extractor, missing "There are two buses a day, it has become very convenient". By adding "first determine whether the original text is sarcasm or rhetorical, and compare after writing the true intention in 1 sentence" to the judge's prompt, false detections became 16→3, missed types of sarcasm became 0, and misses in 65 pairs of sarcasm extractions without words of dissatisfaction also became 0 / 31 (from 16 / 31 before the addition). Misses in turning emotions into evaluative words (5-6 cases out of 12) remain.

For all public data items, it pointed out 5 pairs out of 741 default extraction pairs (all 5 valid by visual inspection), and there were 0 pairs for the extraction with rules. It can be used not as a pass/fail gate, but as a step to pass rare rewrites to human review.

In the English public data (example-polis), the judge sometimes reads provocative assertions asking for pros and cons ("AI corporations don't need local consent…; their expertise suffices.") as sarcasm, and points out literal extractions (1 to 2 cases out of 342). Adding "do not consider it sarcasm if there are no clues" to the instructions did not stop it, so it is treated as a type that reviewers should know about.

Suggestions for Developers

  1. Return the output of default input/output example 2 to "need to do" (A difference of 1 line reduces the strengthening to obligation. The side effects are small).
  2. Make the extraction prompt with rules selectable for users who value faithfulness (write in the description about the side effects of increased direct copies and cutting out other people's remarks as separate opinions, and that sarcasm requiring common sense will remain).
  3. In the recommended configuration for local LLMs, write it as mandatory to have a delivery that enforces JSON schema as a grammar constraint (Ollama's format, llama.cpp's response_format, etc.).
  4. For input in other languages, rewriting is reduced just by using the prompt with rules (Suggestion 2). In 342 English public data items, without inserting a translation stage, it was 2→0 cases for 31B and 5→2 cases for 27B (default → with rules, visual inspection of judge's points). Even if a translation stage is added under the rules, there is no additional gain (remains 0 cases for 31B and 2 cases for 27B), and translation increases the splitting of opinions and introduces new rewrites like dropping "could". If left as the default prompt, separating translation into another stage reduces cases to 4→2 for 27B and 1→0 for 31B out of 60 visually inspected cases.
  5. Immediately after extraction, consider a stage that displays an "attention required" mark on the management screen (not used for pass/fail) based on a mechanical check for empty, match with input/output examples, and overlap with the original text, as well as the judge (in a form that makes it write the true intention of the original text first). The match with input/output examples picked up all 23 fabricated items by 2B using character 2-gram overlap (similarity to example 0.5 or higher and higher than similarity to original text), and had 0 false detections in about 19,000 Japanese outputs of 27B and 31B. It cannot be used when the original text is not Japanese (the 3 default input/output examples are translations of English comments from example-polis, and their correct extraction matches the examples).
  6. Write in the prompt's comments or docs that the default input/output examples are made from the bundled example-polis comments. When evaluating extraction with example-polis, the model sees the answers in the prompt for 3 items.

Open Questions

  • Can sarcasm requiring common sense (which is only half fixed by the prompt) be supplemented by a check with a model of a different lineage (the 31B judgment was able to point out two-thirds of 27B's literal readings)?
  • The occurrence rate of rewriting in actual broad listening data (which has many broken short sentences). Public data has many well-formed sentences, and even with the default it was 0.7%.
  • In the main body's clustering passing through UMAP, to what extent are polarity reversals counted on the opposite side?
