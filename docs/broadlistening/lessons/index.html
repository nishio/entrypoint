Lessons from Practice

Insights from the development of Kouchou-AI.

Concepts

  • Analysis Stance — Kouchou-AI is a tool based on the structure-grasping stance, not the quantitative analysis stance. Rather than understanding the whole picture merely through cluster sizes and frequency distributions, its purpose is to let users read the overall structure.
  • Broadlistening — Broadlistening is a method that uses LLMs to aggregate and cluster large-scale free-text opinions to create a "map of opinions."
  • Pipeline — The analysis pipeline consists of extraction, embedding, hierarchical clustering, labelling, and visualization.

Extraction

  • Extraction Faithfulness Public Models 2026-10-08 — The opinion extraction step of Kouchou-AI can alter the original meaning even if the process completes successfully. By adding specific rules and an instruction to "verify the true intent first" to the prompt, semantic rewriting is significantly reduced, though smaller models require strict JSON constraints to function properly.
  • Local LLM Extraction Faithfulness 2026-10-05 — Extracting Japanese opinions from short foreign-language texts using a small local LLM caused subjective reversals, fabricated relationships, and dropped requests despite completing the process. Successful completion should not be considered success; results must be verified against the original text before adoption.

Labeling

  • Label Coverage Policy 2026-05-29 — Human judgment on label design dictates that labels should act as "summaries" rather than "tables of contents," covering the top 2 to 3 axes. One root cause of missing dimensions in labels is the upstream random sampling limitation of 10 to 30 items per cluster.
  • Label Quality Rubric Evaluation 2026-05-29 — Cluster label quality judgments should be broken down into a rubric evaluation using binary criteria, weights, and fatal penalties rather than abstract 1-5 point scales. This should initially be run as an experimental artifact calibrated against human judgments before entering the standard pipeline.
  • Human Pairwise Label Preference Experiment 2026-06-02 — In label quality experiments, instead of having humans critique isolated labels, they should compare multiple label candidates generated from the same evidence using blind A/B testing. This pairwise preference data can then be used to calibrate the automated judge.
  • Labelling Prompt Few Shot Template Confound 2026-06-03 — Human preference A/B testing showed a unanimous preference for sibling-aware refined labels over unrefined ones, as refinement effectively reduced verbosity. The results highlight that the verbosity reduction and sibling-awareness effects are intertwined, while prompt templating issues remain valid.

Clustering and Visualization

  • LLM Grouping Experiment — The initial experiment for LLM grouping should run `analysis_mode=llm_grouping` on 400 Japanese comments to observe the limits of its scatter-compatible visualization.
  • UMAP Seed History — The seed fixing for UMAP and k-means originated from a desire to minimize visual fluctuations rather than achieving strict reproducibility. It was later reconsidered as a trade-off against parallel processing capabilities.
  • Graph Visualization Proposal 2026-05-25 — Moving away from burdening UMAP 2D with both semantic clustering and visualization quality, this proposes a graph drawing visualization using intra-cluster MSTs and inter-cluster bridge edges. This approach serves as a visualization-side answer to existing critiques of the current algorithm.
  • Auto Cluster Defaults — The essence of the default cluster number issue lies in the inconsistency between documentation, implementation, and AI usage paths rather than pure algorithm selection. PR #832 is a fix aimed at narrowing this gap.

Public UI and Scope

  • Public UI Requirements for Broadlistening — The requirements for a public UI of broad listening results are not about whether it uses a scatter plot, but rather visualizing volume, perspectives, issues, and paths to individual opinions. It must also avoid burying minority opinions, eliminate arbitrariness, and visualize the next questions.
  • Kouchou AI Scope Line from Marketing to Plugin 2026-06-03 — Tracing the scope boundary that "Kouchou-AI's scope ends at discovering key insights, with everything beyond left to accompanying partners." This consistent boundary has shaped the product's direction from early marketing strategy meetings to current plugin policies.

Peripheral Topics

  • KJ Method Broadlistening Framing 2026-05-25 — A teleological discussion connecting Kouchou-AI to the KJ method's public hypothesis formation. It separates unverified hypotheses—such as KJ method prompts improving quality—from product design principles.
  • Pipeline Step Addition Framing 2026-05-27 — Proposals to add pipeline steps should be judged by whether they introduce new, first-class artifact responsibilities rather than mere step counts. Boundary cases, counterexamples, and bridges should become independent artifacts, while simple label copy improvements remain experimental optional steps.
  • Public Tool Catalog Draft 2026-06-30 — A draft tool catalog to clearly explain Kouchou-AI, Idobata, Cartographer, Jigsaw Sensemaker, and tttc-light-js to external audiences without confusion. This will be repurposed for public case study pages and technical event materials.
  • Broad Listening Book Extractions — Extracting insights from the book that influence future development decisions by separating design intentions, empirical rules, and verified results. The improvement in quality from KJ method prompts is explicitly treated as an unverified hypothesis.
